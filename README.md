# AI Systems Fluency

A technical field guide to AI inference, infrastructure and performance, based on the supplied technical learning plan. The site includes eleven chapters, 27 technical cards, engineering questions, a glossary and a four-week practice plan.

The cards turn the learning plan into structured explanations, examples, mental models, metrics and engineering questions. Edit the card content directly in `index.html`; each card is an `<article>` with an ID such as `card-1`. `learning-plan.pdf` is an optional reference copy of the source, with one comparison exercise removed.

The site is static and has no build step or external dependencies. To preview locally, run `python3 -m http.server 8000` in the repository and open `http://localhost:8000/`. Card search requires JavaScript; the guide remains readable without it.

GitHub Pages publishes the site from the `main` branch.
