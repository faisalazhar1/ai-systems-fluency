# AI Systems Fluency

A technical field guide to AI inference, infrastructure and performance, based on the supplied technical learning plans. The site includes ten chapters, 30 technical cards, engineering questions and a glossary.

The cards draw on the learning plans' wording, examples, diagrams and questions. Edit the card content directly in `index.html`; each card is an `<article>` with an ID such as `card-1`.

The site is static and has no build step or external dependencies. To preview locally, run `python3 -m http.server 8000` in the repository and open `http://localhost:8000/`. Card search requires JavaScript; the guide remains readable without it.

GitHub Pages publishes the site from the `main` branch.
